# 931400 精筛落点开发验证

以原服务器的布局 931400、第 450 步夹持汤罐状态为分叉。三个分支均要求初态、原动作共同前缀、分叉物理状态和双相机 RGB-D 与归档一致。

| 分支 | 分叉后的控制 |
|---|---|
| 归档 π₀.₅ 接续 | 重放策略种子 48 对应的原动作及终止条件。 |
| 右移对照 | 用原左右 30 毫米规则选点，保持分叉时末端朝向。 |
| 精筛落点 | 保持同一末端朝向，目标水平位置取固定持罐姿态净空筛查的候选。 |

精筛读取 SHA-256 锁定的 CPU 结果。以标称竖直路径至少 3 毫米净空为准入，在各轴 ±1 毫米的采样偏差内要求有正净空。按偏差下最差净空降序、标称净空降序、到篮中心距离升序确定唯一目标。严格要求偏差下仍有 3 毫米的 CPU 结果单独保留。

两种几何放置使用同样的原生 OSC、阶段预算及目标高度。目标罐中心高度为官方区域 z 上界加 25 毫米。开爪前仍须持罐，罐中心水平误差不超过 1 毫米、竖直误差不超过 10 毫米，罐体朝向偏差不超过 1 度。逐步记录脱手、官方谓词、位姿、接触力和已完成目标变化。

主要结局为脱手后最后连续 20 步均保持三个官方目标、三物体均未被夹持且汤罐中心跨度不超过 5 毫米。已完成目标反转或重抓计为失败。该配对覆盖一个已见的开发状态，使用评估器物理真值选点。
