# 双相机估计的开爪门槛与补偿方向验证

用三个旧开发分叉 935632、935634、935635 的真实持罐瞬间标定汤罐相对夹爪的中心和旋转先验。中心取分量中位数，旋转取旋转平均。冻结旧分叉、RGB-D 帧及模型文件哈希。新数据推理输入包括双相机 RGB-D、标定、末端位置和夹爪开度。汤罐模型独立加载锁定的 LIBERO 视觉网格。

每个分叉先用分叉帧和最后持罐下降帧分别估计完整位姿。把三维初值放入世界坐标系。前视用近爪蓝黄标签颜色选点，两路用深度连续性和初始模型深度的一致性选点。沿标定射线求锁定网格的表面深度，以鲁棒损失联合拟合每帧的旋转和平移。开发帧的前视深度有约 0.6 毫米整体偏差，因此前视残差减去每帧拟合的轴向中位偏差，用来约束表面形状。腕部保留绝对深度约束。两帧的相对旋转给出估计角差和世界坐标补偿，模型只含汤罐。[MuJoCo 射线接口](https://mujoco.readthedocs.io/en/3.2.3/APIreference/APIfunctions.html#mj-multiray)

## 新持罐分叉

- 使用完成占用前缀且尚无合格持罐放置的候选。按已有候选顺序，以 935640、935641 为双占用组，另采最多两个符合条件的仅奶酪组。沿用已归档前缀、参考抓取和五点净空筛查。所有候选、资格不足和筛查弃权保留在记录中。
- 从同一合格持罐分叉使用固定姿态臂和已冻结的仿真反馈臂生成自然的门槛两侧观测。先审计物理配对，再分别对两个端点估计姿态。相同终点状态哈希只计一次。仿真反馈臂只提供物理对照，估计器的输入不含罐体、篮内物体或转轴真值。
- 在持罐且位置满足水平 ≤1 毫米、竖直 ≤10 毫米的唯一采样终点上统计误放、误拦、弃判，以及全部配对的观测覆盖。估计角差用 1° 判定，距门槛 ≤0.10° 时弃判。另记录无缓冲带时的判定和原因。
- 对真实角差超过 1° 的端点，比较真实与估计补偿向量的方向余弦。用原有 3° 上限截断估计补偿，将其施加到已记录的罐体旋转后复算剩余角差。这些指标验证几何方向，实际控制效果另用在线对照检验。
