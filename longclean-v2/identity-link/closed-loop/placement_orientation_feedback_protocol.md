# 拥挤篮放置的汤罐姿态反馈

在实验前冻结。两臂从同一原生状态和同一开爪前筛查落点出发。每步核对汤罐、夹爪和已完成目标。沿用 320 步预算、开爪时水平误差 ≤1 毫米、竖直误差 ≤10 毫米、汤罐角差 ≤1 度，以及脱手后 20 步稳定验收。

- 反馈只用于持罐下降阶段。当位置合格但角差超过 1 度连续出现 20 个控制状态时，根据实测罐体相对夹爪的朝向计算末端目标。以分叉时夹爪朝向为基准，姿态补偿最多 3 度。开爪并撤离时保持开爪前的实测末端姿态。未触发的反馈臂应与固定姿态臂逐步一致。
- 开发组使用 935632、935635 两个已知被角差阻断的分叉和 935634 的成功分叉，全部沿用旧的开爪前筛查落点。固定姿态臂必须精确复现存档。至少救回一个原失败分叉，保留 935634 的稳定成功，并且已入篮目标零反转、零重抓，才进入独立对照。
- 通过开发准入后，从 935636–935641 按序取前四个合格持罐分叉。它们此前仅参与占用采集，未执行放置。沿用归档参考抓取和固定的五点开爪前筛查，资格和选点均不读取放置结局。筛查弃权单列，所有合格分叉计入覆盖。
- 记录每条轨迹的控制目标、逐步匹配状态、实际开爪、脱手、三目标稳定和回退。预估姿态来自仿真位姿，结论限于仿真放置模块。
