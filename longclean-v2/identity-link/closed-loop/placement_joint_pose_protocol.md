# 罐身纹理与相对姿态的联合拟合验证

沿用旧开发集冻结的 CAD 网格、夹爪标定和传感深度设置。分叉与下降终点共享一份罐体相对夹爪的参考旋转，在夹爪坐标系中同时拟合两帧独立平移、共同参考旋转及两帧相对转动。低权重旋转先验约束退化方向。深度采用隔离 CAD 射线和两路鲁棒残差。前视拟合轴向中位偏差，腕部保留绝对深度。[上一轮双相机协议](placement_rgbd_pose_protocol.md)

先求联合深度解。用该解和测量标定双向投影，在原始深度支持内选取罐身颜色点，冻结共同可见的纹理像素。以深度解为起点继续联合拟合颜色比例与去除整体偏差的亮度，降低亮度权重。纹理项约束两帧相对转动。输入只有双相机 RGB-D、相机标定和夹爪状态。完整旋转及补偿方向用独立侧录评分。

- 先运行已见的 935613 固定姿态端点，比较联合深度与联合纹理方法。另保留 935612 两臂作已见对照。主方法必须正确允许 935613，对已知超限的 935612 原始判定给出拦截或弃判，以及给出方向余弦为正的补偿。通过后冻结回归报告、源码、标定和协议哈希。
- 新布局按编号尝试 935614–935617。四个布局沿用已归档奶酪盒入篮前缀，之前均未取得合格持罐分叉。沿用原生参考抓取、提罐资格和五点净空筛查，所有采集与筛查失败独立记账。
- 每个合格落点跑固定姿态与冻结的仿真反馈臂以生成原生测量。物理状态相同的端点去重。用持罐且位置公差合格的终点验收 1° 角差，距门槛 0.10° 内弃判，并保留直接判定统计。纹理支持不足、拟合越界或深度残差过大时记录弃判原因。
- 对真实超限端点记录方向余弦和用 3° 幅度上限进行几何补偿后的剩余角差。所有估计先以旁路回放评分。
